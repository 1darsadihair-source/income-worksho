# دفترکار دانشجو | کارگاه اجرایی درآمد

این دفترکار را برای یک کسب‌وکار/پیشنهاد در هر چرخه تکمیل کن. اطلاعات شخصی مشتری را حداقل نگه دار و بدون رضایت، مکالمه خصوصی را منتشر نکن.

## برگه ۱ ـ نقطه شروع

- مهارت/دارایی فعلی من:
- گروهی که به آن دسترسی دارم:
- مسئله احتمالی:
- تجربه یا مشاهده‌ای که این فرضیه را ساخته:
- آنچه هنوز نمی‌دانم:
- چه چیزی می‌تواند فرضیه را رد کند؟
- محدودیت زمان، پول، ابزار و ظرفیت من:
- مرز اخلاقی/حرفه‌ای خدمت:

## برگه ۲ ـ فرضیه مسئله

- گروه مشخص:
- موقعیت وقوع:
- کاری که فرد می‌خواهد انجام دهد:
- مانع:
- پیامد قابل مشاهده:
- راه‌حل فعلی:
- هزینه/تلاش فعلی:
- نشانه‌های موافق:
- نشانه‌های مخالف:
- پرسش بعدی:

## برگه ۳ ـ برنامه مصاحبه

- هدف یادگیری (نه هدف فروش):
- معیار انتخاب مشارکت‌کننده:
- تعداد/تنوع مشارکت‌کنندگان و دلیل انتخاب:
- روش جذب و رضایت:
- سؤال آغازین درباره آخرین تجربه:
- پرسش درباره رفتار واقعی:
- پرسش درباره راه‌حل جایگزین:
- پرسش درباره هزینه/پیامد:
- پرسش درباره تصمیم‌گیرنده:
- پرسش پایانی:
- خطر سؤال هدایت‌گر و راه پیشگیری:

## برگه ۴ ـ خلاصه مصاحبه

- شناسه بی‌نام:
- تاریخ:
- زمینه و رویداد:
- نقل‌قول دقیق با رضایت:
- رفتار مشاهده‌شده/گزارش‌شده:
- راه‌حل فعلی:
- هزینه یا تلاش:
- مانع تصمیم:
- شواهد موافق:
- شواهد مخالف:
- تفسیر من (جدا از واقعیت):
- پرسش باز:
- اقدام بعدی:

## برگه ۵ ـ ماتریس الگوها

| الگو/نیاز احتمالی | مصاحبه‌های پشتیبان | شواهد مخالف | گروه/زمینه | سطح اطمینان توصیفی | گام بعد |
|---|---|---|---|---|---|
| | | | | | |

از شمارش خام نقل‌قول‌ها به‌عنوان تخمین اندازه بازار استفاده نکن. نمونه مصاحبه، نمونه آماری نماینده بازار نیست مگر با طراحی مناسب.

## برگه ۶ ـ طراحی پیشنهاد

- نام موقت:
- مخاطب واجد شرایط:
- مسئله مستند:
- خروجی قابل مشاهده:
- روش/مراحل:
- موارد شامل:
- موارد غیرشامل:
- زمان تحویل:
- مسئولیت مشتری:
- قیمت و روش پرداخت:
- هزینه مستقیم برآوردی و مبنای آن:
- ریسک‌ها و وابستگی‌ها:
- شرایط لغو/بازپرداخت:
- شواهدی که می‌توانم صادقانه ارائه کنم:
- ادعایی که نباید مطرح کنم:
- شرطی که باعث می‌شود پیشنهاد را ارائه نکنم:

## برگه ۷ ـ گفت‌وگوی فروش

- هدف مکالمه:
- آنچه از نیاز مشتری فهمیدم:
- خلاصه‌ای که برای تأیید به او گفتم:
- چرا پیشنهاد مناسب است/نیست:
- گزینه‌ها و محدودیت‌ها:
- اعتراض یا پرسش:
- پاسخ شفاف من:
- تصمیم فعلی:
- گام بعدی و تاریخ:
- آیا مشتری برای ادامه رضایت دارد؟

## برگه ۸ ـ ثبت فرصت

| شناسه | تاریخ ورود | منبع | مرحله | پیشنهاد/مبلغ | آخرین تماس | گام بعدی/تاریخ | نتیجه/علت مستند |
|---|---|---|---|---:|---|---|---|
| | | | | | | | |

## برگه ۹ ـ آزمایش فروش

- مسئله‌ای که می‌خواهم حل کنم:
- فرضیه قابل رد:
- تغییر واحد (فقط یک تغییر اصلی):
- مخاطب و معیار واجد شرایط بودن:
- کانال:
- معیار اصلی:
- معیار محافظ (مثلاً شکایت، لغو، هزینه یا کیفیت):
- بازه و حجم موردنظر:
- چه نتیجه‌ای ادامه را توجیه می‌کند؟
- چه نتیجه‌ای باعث اصلاح می‌شود؟
- چه نتیجه‌ای باعث توقف می‌شود؟
- عوامل مخدوش‌کننده:
- نتیجه واقعی و محدودیت داده:

## برگه ۱۰ ـ اقتصاد واحد

- قیمت هر واحد:
- تعداد فروخته‌شده:
- فروش ثبت‌شده:
- وجه وصول‌شده:
- تخفیف/برگشت وجه:
- هزینه مستقیم هر واحد:
- تعداد ساعت تولید/تحویل:
- هزینه ابزار/کانال:
- هزینه جذب مشتری (تعریف و داده):
- هزینه ثابت دوره:
- سهم هر واحد پیش از هزینه ثابت:
- نقطه سربه‌سر تقریبی:
- مالیات/کارمزد/هزینه‌های احتمالی که هنوز بررسی نشده:
- تصمیم و حساسیت آن به فرضیات:

**کنترل:** فروش ثبت‌شده با پول وصول‌شده یکی نیست؛ سود با گردش پول یکی نیست؛ زمان خودت نیز هزینه واقعی ظرفیت است.

## برگه ۱۱ ـ مرور هفتگی

- مهم‌ترین مشاهده واقعی:
- مهم‌ترین فرضیه‌ای که هنوز اثبات نشده:
- شواهد مخالف:
- تعداد فرصت‌های واجد شرایط:
- پیشنهادهای ارسال‌شده:
- پرداخت‌های وصول‌شده:
- هزینه‌ها:
- گلوگاه محتمل:
- اقدام واحد هفته آینده:
- معیار سنجش:
- ریسک یا رفتار غیراخلاقی که باید از آن اجتناب کنم:

## برگه ۱۲ ـ گزارش نهایی

- مسئله و مخاطب منتخب:
- شواهد و محدودیت‌های آن:
- پیشنهاد نهایی:
- آزمایش انجام‌شده:
- نتایج واقعی (با تاریخ و تعریف):
- چه چیزی شکست خورد یا نامشخص ماند:
- تغییر بعدی:
- مهارتی که هنوز نیاز به تمرین دارد:
- پیوست‌های قابل بازبینی:
